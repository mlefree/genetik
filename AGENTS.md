# Projet généalogique

La mémoire de recherche, les objectifs actifs et le protocole de travail sont
définis dans `recherche/AGENT.md`. Toujours lire ce fichier avant une recherche,
un import familial ou une modification de l'arbre.

`recherche/` est privé et exhaustif ; `docs/` est public et sélectif. Ne jamais
publier automatiquement une source ou une information sur une personne vivante.
Ne pas reconstruire le site ni lancer toute la suite de contrôles après une simple
recherche : ces opérations doivent répondre au goal courant.

La section « Mécanique du dépôt » de `recherche/AGENT.md` est à lire avant toute
écriture dans `arbre_source.json` ou dans le registre `medias` : elle décrit les
conditions exactes pour qu'une pièce apparaisse sur une fiche, les champs
recalculés à l'exposition, les niveaux de preuve, les droits de rediffusion par
fournisseur et l'état d'accès des dépôts.
